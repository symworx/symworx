# SymWorx

**SymWorx** is a cross-platform framework for developing mathematical models and simulations. It provides a Rust kernel with Python wrappers, offering consistency and reliability across systems.

It is part of the **Computational Systems for Modeling & Dynamics** (cSYM-d) ecosystem.

**Components:**
The SymWorx repository contains a monorepo with a variety of tools, including Rust crates and Python packages.

**Target Audience:**
SymWorx is primarily intended for educational and research purposes. The Python wrappers are designed for teaching and research environments, while the Rust kernel supports embedded systems and web applications.

**Versioning Issues:**
If you encounter Python versioning issues, you can set environment variables to specify the Python version:

```
export PYO3_PYTHON=python3.12
export PYTHON_SYS_EXECUTABLE=python3.12
```
